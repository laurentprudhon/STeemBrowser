# MC6850 ACIA

> The Motorola MC6850 is an Asynchronous Communications Interface Adapter used for the keyboard serial link and MIDI interface.

## Overview

| Parameter | Value |
|-- | ---- |
| Manufacturer | Motorola |
| Package | DIP40 |
| Function | Asynchronous Communications Interface Adapter |
| Channels | 1 (in ST configuration) |
| Data format | 7 or 8 data bits, optional parity, 1 or 2 stop bits |
| Max baud | 115.2 Kbps |
| Address | $FF8C00-$FF8CFF range (memory-mapped) |

## MC6850 Pinout (DIP-40)

Key pins:

| Pin | Signal | Description |
|-----|- -----|--|
| 1-8 | DA0-DA7 | Data bus |
| 12-13 | A1, A2 | Address lines |
| 17 | CS2 | Chip select (active low) |
| 18 | RESET | Reset (active high) |
| 22 | RXD | Receive data input |
| 23 | TXD | Transmit data output |
| 26 | RTS | Request to Send |
| 28 | CTS | Clear to Send |
| 30 | DCD | Data Carrier Detect |
| 38 | CLOCK | Clock input |

## Memory Mapping

The MC6850 ACIA is memory-mapped in two places:

| Function | Keyboard Address | MIDI Address |
|------|------|--|
| Control/Status | $FFFC00 | $FFFC04 |
| Data | $FFFC02 | $FFFC06 |

## Registers

### Control/Status Register

| Bit | Name | Description |
|-----|------|------|
| 0 | DR | Data Ready (1 = data available to read) |
| 1 | TDF | Transmitter Data Full (1 = data in DR ready to transmit) |
| 2 | E | Error (1 = framing error) |
| 3 | OE | Overrun Error (1 = new data arrived while previous unread) |
| 4 | CTS | Clear to Send (1 = CTS asserted) |
| 5 | DCD | Data Carrier Detect (1 = DCD asserted) |
| 6-7 | - | Not implemented |

### Control Register (Write)

| Bits | Name | Description |
|------|------|--------|
| 0 | RIE | Receiver Interrupt Enable |
| 1 | TIE | Transmitter Interrupt Enable |
| 2 | PS0 | Parity Select bit 0 |
| 3 | PS1 | Parity Select bit 1 |
| 4 | PBS | Parity Enable Bit Select |
| 5 | S0 | Stop Bits Select bit 0 |
| 6 | S1 | Stop Bits Select bit 1 |
| 7 | RST | Reset (write 1 to reset ACIA) |

Data format:

| S1 | S0 | Stop Bits |
|----|----|------|
| 0 | 0 | 1 stop bit |
| 0 | 1 | 1.5 stop bits |
| 1 | 0 | 2 stop bits |
| 1 | 1 | 1 stop bit |

PS1 | PS0 | Parity |
|----|----|----|
| 0 | 0 | No parity |
| 0 | 1 | Odd |
| 1 | 0 | Even |
| 1 | 1 | Mark |

## Keyboard Serial Interface

The keyboard connects to the ST console via:
- **HD6301** microprocessor in the keyboard
- **MC6850** ACIA in the ST console
- **Serial link**: 7.8125 Kbps (fixed)

Keyboard scan codes are transmitted as serial data through the ACIA. Each key press and release generates a make code or break code (high bit set).

## MIDI Interface

The MIDI port connects data through the same ACIA:

- **MIDI In**: RXD input ($FFFC04 control, $FFFC06 data)
- **MIDI Out**: TXD output (from ACIA)
- **MIDI protocol**: 31.25 Kbps, 8 data bits, 1 stop bit, no parity
- **MIDI through**: Opto-coupled loop from MIDI In to MIDI Out

## Emulator Notes

- The ACIA uses an internal baud rate generator
- For keyboard: the ACIA is at $FFFC00/$FFFC02 (keyboard) and $FFFC04/$FFFC06 (MIDI)
- When writing to control register, only bits 0-7 matter (data bits 0-7 of control register)
- Reading control register returns status bits 0-5 (data ready, transmitter full, error, overrun, CTS, DCD)
- The RST bit can only be written, never read back
