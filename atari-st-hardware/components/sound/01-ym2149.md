# YM2149 Programmable Sound Generator

> The Yamaha YM2149 (or YM2149F) is a 3-channel mono PSG chip used in the Atari ST. Also known as the YM2149S/S/F variant. Pin-compatible with the Yamaha AY-3-8910 and the General Instruments AY-3-8910.

## Overview

| Parameter | Value |
|-----------|-------|
| Manufacturer | Yamaha Corporation |
| Package | DIP40 |
| Supply voltage | 5V |
| Power consumption | ~125 mW typical |
| Clock input | Internal (no external clock needed) |
| Channels | 3 tone generators + 1 noise generator |
| I/O ports | 2 × 8-bit bidirectional I/O ports |
| Register interface | AY-3-8910 compatible |
| Data bus | 8-bit (D0-D7) |
| Frequency range | 30 Hz to > 20 kHz (depends on clock) |

### Bus Control

The YM2149 is controlled via the bus control inputs (SEL, A8, A9, BC1, BDIR):

| SEL | A9 | BDIR | BC1 | Operation |
|-----|-----|------|-----|------|
| 0 | X | 0 | 0 | No operation |
| 0 | X | 0 | 1 | Write DA0-DA7 to selected register |
| 0 | X | 1 | 0 | Read DA0-DA7 from selected register |
| 0 | X | 1 | 1 | No operation |
| 1 | 0 | 0 | X | Select register A8-A9 = $0 (Port A data) |
| 1 | 0 | 1 | X | Select register A8-A9 = $2 (Port B data) |
| 1 | 1 | X | X | Select register based on A8-A9 |

In practice, on the Atari ST, the YM2149 is memory-mapped at `$FF8800-$FF88FF`. Writing to `$FF88xx` where x = register number selects the register, and `$FF8802` provides the data.

### Noise Generator

The noise generator produces white noise or a periodic sequence:

| Noise Period bits | Range | Notes |
|------|--|------|
| 5 bits | 0-31 | Frequency divider |

The noise source can feed all three channels or be disabled.

### Mixer Control Register ($FF8807) - Bit Map

| Bit | Name | Description |
|----|----|------|
| 0 | OUT1L | Output 1 left channel enable for mixer |
| 1 | OUT1R | Output 1 right channel enable for mixer |
| 2 | CH1 | Channel A mixer enable |
| 3 | IN1A | Channel A tone select (1=enabled) |
| 4 | CH2 | Channel B mixer enable |
| 5 | IN1B | Channel B tone select |
| 6 | CH3 | Channel C mixer enable |
| 7 | IN1C | Channel C tone select |

### Envelope Shape Register ($FF880D)

| Bit | Name | Default | Description |
|-----|------|--------|------|
| 0 | C | 0 | Continuous (1) or Gate (0) |
| 1 | R | 0 | Ramp (1) or Step (0) |
| 2 | A | 1 | Alternate (1) or Continuous (0) |
| 3 | H | 1 | Hold (1) or Stop (0) |
| 4-7 | - | 0 | Not implemented |

### Envelope Period

The envelope period is determined by:
```
Envelope Period = 2 × (Coarse + 1) × 2^(Fine) / f_CPU
```

Where f_CPU is the system clock (8 MHz on Atari ST).

## Audio Output

The YM2149 has three analog output pins:

| Pin | Signal | Description |
|-----|--------|------|
| 3 | Ch B | Analog output channel B |
| 4 | Ch A | Analog output channel A |
| 29 | Ch C | (via DA7 through resistor network) |

On the Atari ST, the outputs are mixed through resistors into the audio output via the DIN13 connector (pin 1: Audio out).

## Frequency Calculation

The tone generator frequency is calculated as:

```
Frequency = f_clock / (20 × N × R)
```

Where:
- `f_clock` = 8 MHz (Atari ST system clock)
- `N` = frequency divisor (16-bit value written to channel registers)
- `R` = noise period / noise generator setting

For a given desired frequency:
```
N = f_clock / (20 × R × frequency)
```

Example for middle C (261.63 Hz) with R=8:
```
N = 8000000 / (20 × 8 × 261.63) ≈ 191
```

## I/O Port Usage on Atari ST

### I/O Port A ($FF880E) - Output Only
| Bit | Function | Atari ST usage |
|-----|----------|------|
| 0 | IOA0 | MIDI out data (through ACIA) |
| 1 | IOA1 | Joystick trigger |
| 2 | IOA2 | RS232 handshake / LED control |
| 3 | IOA3 | RS232 RTS (Ready To Send) |
| 4 | IOA4 | RS232 DTR (Data Terminal Ready) |
| 5 | IOA5 | Unused (or parallel port direction) |
| 6 | IOA6 | Unused |
| 7 | IOA7 | Unused |

### I/O Port B ($FF880F) - Data
| Bits | Function | Atari ST Usage |
|------|------|------|
| 0-7 | IOB0-IOB7 | Data lines for Centronics parallel port (printer) |

I/O Port B data is the 8-bit parallel port data output to the printer.

## Emulator Notes

- The YM2149 has no internal clock generator - the internal clock is derived from the system clock
- The audio output is analog via internal DACs mixed at the output pins
- The PSG is **analog in nature**: frequency determination uses internal counters
- Each channel has a 14-bit frequency divider (not independent) - shared divider across all channels
- Volume control is achieved by amplitude control (not true gain)
- In the original ST, channels A and B drive the two stereo channels (via mixer) while channel C is typically unused
- The noise generator can feed all 3 channels simultaneously or be disabled
