# WD1772A Floppy Disk Controller

> The Western Digital WD1772A / WD1772-10 is the floppy disk controller chip. It handles reading/writing MFM-encoded data from 3.5" floppy drives.

## Overview

| Parameter | Value |
|------|-----|
| Manufacturer | Western Digital |
| Package | DIP40 |
| Part variants | WD1772, WD1772A, WD1772-10, WD1772C |
| Speed | 15 MHz (WD1772), 10 MHz (WD1772-10), 8 MHz (WD1772C) |
| Compatibility | 1790/2790 compatible |
| Encoding | MFM (Modified Frequency Modulation) / FFM |
| Sectors per track | up to 63 (type II format) |
| Data rate | up to 250 Kbps |
| Interfaces | 6 control pins, 8-bit data bus, interrupt output |

## FDC Registers

### Mapping on Atari ST

The FDC is accessed via the DMA configuration register at `$FF8600-$FF86FF`:

| ST Address | FDC Register | Read/Write | Description |
|------|------|---------|------|
| $FF8601 | Read Status | R | Status register |
| $FF8605 | Track | R/W | Current track number |
| $FF8603 | Sector | R/W | Sector number |
| $FF8607 | Data | R/W | Data register |
| $FF8604 | Access Byte (command/data) | R/W | Command byte or data depending on config |
| $FF8606 | Configuration | R/W | DMA configuration / register select |

### FDC Status Register ($FF8601, read via config $FF8600)

| Bit | Name | Description |
|-----|- -----|------|
| 0 | READY | Drive ready |
| 1 | DATA | Data register ready (bit 1) |
| 2 | DMAREQ | DMA request active |
| 3 | INDEX | Index pulse detected |
| 4 | MOTOR | Motor on (bit 7) |
| 5 | !INTRQ | Interrupt request active (bit 5, inverted) |
| 6 | - | Unused |
| 7 | !BUSY | FDC busy (bit 7, inverted) |

### Configuration Register ($FF8606)

| Bit | Name | Description |
|-----|- -----|------|
| 7 | FDC/HDC | 1 = FDC, 0 = HDC |
| 6 | DMA | 1 = enable DMA transfer |
| 5 | WRIT | 1 = write mode, 0 = read mode |
| 4 | TRACK | 1 = access track register, 0 = access register select |
| 3 | - | Unused |
| 2 | SECTOR | 1 = sector register, 0 = register select |
| 1 | - | Unused |
| 0 | READ | 1 = read register, 0 = write register |

### Writing to FDC Registers

Register select value (bits 0, 4) determines which internal register is selected:

| Reg Sel (bits 4,0) | Internal Register |
|-----|---|--|
| 00 | Register 0 (Status) |
| 20 | Register 1 (Track) |
| 04 | Register 2 (Sector) |
| 06 | Register 3 (Data) |
| 02 | Register 4 (Access Byte) |
| 07 | Register 5 (Config) |

### Commands (Write to Access Byte Register $FF8604)

| Command | Hex Value | Description |
|-----------|- --|------|
| Restore | 0x00 | Move head to track 0 |
| Seek | 0x10 | Seek to specified track |
| Step | 0x20 | Step head one track |
| Step In | 0x40 | Step head inward |
| Step Out | 0x60 | Step head outward |
| Read Sector | 0x80 | Read one sector |
| Write Sector | 0xA0 | Write one sector |
| Read Address | 0xC0 | Read sector address mark |
| Read Track | 0xE0 | Read raw track data MFM |
| Write Track | 0xF0 | Write raw track data MFM |

Command modifiers (OR into command):

| Modifier | Hex | Description |
|-----|- -|--|
| Update Track | 0x10 | Update track register after seek |
| Multiple Sector | 0x10 | Multiple sector (read/write) |
| Add 30ms Delay | 0x04 | Add delay after command |
| Write Precomp Disabled | 0x02 | Disable write precompensation |
| Write Deleted Data Mark | 0x01 | Set deleted data mark |
| End with no interrupt | 0x00 | No interrupt on completion |
| Interrupt on index pulse | 0x04 | Interrupt at index pulse |
| Immediate interrupt | 0x08 | Immediate interrupt |

## ST-Specific Emulation Notes

### Floppy Drive Types

| Drive | Capacity | Format |
|---|---|--|
| SF354 | 720 KB (DD 3.5") | 1 sector = 512 bytes, 18 sectors/track (DD), 2 sides |
| SF314 | 720 KB (DD 3.5") | Same as SF354 |
| ST e drive | 1.44 MB (HD 3.5") | 36 sectors/track (HD only supported on Mega STE) |

### Data Encoding

- **MFM encoding**: Each bit is encoded as 2 bit-cells
- **Sector format**: 
  - ID area: `$FA AA ...` (address mark followed by sector info)
  - Data area: `$FE AA ...` (data mark followed by 512 bytes + CRC)
  - GAP area: `$FF` bytes
- **CRC**: CRC-CCITT computed per sector (address mark + sector data)

### DMA Timing

The FDC uses DMA for data transfer. FDRQ is asserted when:
1. A read operation is in progress and sector data is ready
2. A write operation needs to send data to the drive

The DMA handshake:
1. FDC asserts FDRQ (active low)
2. DMA chip asserts FDRQ to CPU
3. CPU responds with BGACK
4. DMA chip takes bus, asserts !ACK to FDC
5. Data transfers
6. FDC de-asserts FDRQ when done

### FDC Timing Registers

| Register | Address | Value | Default | Description |
|------|-----|---|- --|---|
| Config | $FF8606 | 7 | 0x00 | Default config |
| Track | $FF8605 | Track # | 0 | Starting track |
| Sector | $FF8603 | Sector # | 1 | Starting sector |
| Data | $FF8607 | Data | - | Data read/write |
| Access | $FF8604 | Command | - | Command byte |
