# MC68901 Multi-Function Peripheral

> The Motorola MC68901 (also MK68901 by Mostek, HC68901 by Hitachi) is the heart of the Atari ST's interrupt management, system timing, and serial communications.

## Overview

| Parameter | Value |
|-- | ---- |
| Manufacturer | Motorola / Mostek / Hitachi |
| Package | DIP64 |
| Function | Multi-Function Peripheral |
| USART | Single channel, full duplex |
| Timers | 4 independent timers (A, B, C, D) |
| I/O | Eight programmable I/O pins with interrupt |
| Maximum baud | 62.5 Kbps async, 1 Mbps sync |
| DMA handshake | Supported |
| Vector base | Programmable interrupt vector base |

### General Purpose I/O Register A ($FF8001)

| Bit | Function |
|-----|--
| 0 | GPI0 - Parallel port busy
| 1 | GPI1 - RS232 DCD
| 2 | GPI2 - RS232 CTS
| 3 | GPI3 - GPU op done
| 4 | GPI4 - Keyboard/MIDI
| 5 | GPI5 - FDC
| 6 | GPI6 - RS232 RI
| 7 | GPI7 - Monochrome detect

### Data Direction Register A ($FF8005)

Each bit determines if the corresponding GPI pin is input (1) or output (0):

| Bit | Default | Direction |
|-----|- -|-|
| 0 | 1 | Input (parallel port busy) |
| 1 | 1 | Input (RS232 DCD) |
| 2 | 1 | Input (RS232 CTS) |
| 3 | 0 | Output (GPU op done) |
| 4 | 1 | Input (keyboard/MIDI) |
| 5 | 1 | Input (FDC) |
| 6 | 1 | Input (RI) |
| 7 | 1 | Input (monochrome detect) |

### Timer A Control Register ($FF8019)

| Bit | Name | Description |
|-----|------|------|
| 0 | TAI | Timer A interrupt enable |
| 1 | TEA | Timer A enable |
| 2-3 | - | Unused |
| 4-5 | TMC | Timer A mode |
| 6-7 | TMS | Timer A source |

Mode options (TMC):
| TMC | Mode |
|-----|------|
| 0 | Free running (count) |
| 1 | Output square wave |
| 2 | Output one pulse |
| 3 | Event counter |

### Timer B Control ($FF801B)

Same structure as Timer A but used for screen graphics (hblank, sync).

### Timer C & D Control ($FF801D)

| Bits | Name | Description |
|-----|------|------|
| 0 | TACI | Timer C interrupt enable |
| 1 | TEC | Timer C enable |
| 2-3 | - | Unused |
| 4-5 | TMC | Timer C mode |
| 6-7 | TMS | Timer C source |
| 8 | TDCI | Timer D interrupt enable |
| 9 | TED | Timer D enable |
| 10-11 | - | Unused |
| 12-13 | TMC | Timer D mode |
| 14-15 | TMS | Timer D source |

Timer C = system clock (GSX, GEM timing, ~200 Hz)
Timer D = RS232 baud rate generator

### Timer D Baud Rate

Timer D generates the baud rate for the USART:

```
Baud Rate = f_clock / (16 × Timer D value)
```

Where f_clock = 8 MHz (system clock).

Standard baud rates:

| Baud | Timer D Value |
|------|------|
| 50 | 10000 |
| 300 | 166 |
| 1200 | 41 |
| 2400 | 20 |
| 4800 | 11 |
| 9600 | 5 |
| 19200 | 2 |
| 38400 | 1 |

### USART Control Register ($FF8029)

| Bit | Name | Description |
|-----|------|------|
| 0 | RIE | Receiver interrupt enable |
| 1 | TIE | Transmitter interrupt enable |
| 2 | RP | Receive parity |
| 3 | TP | Transmit parity |
| 4 | PS | Parity select (even/odd) |
| 5-6 | SBS | Stop bits select |
| 7 | RXS | Receiver status |

### Receiver/Transmitter Status

| Bit | RSR (Receiver) | TSR (Transmitter) |
|-----|------|-----|
| 0 | OR | Framing error |
| 1 | OE | Overrun error |
| 2 | PE | Parity error |
| 3 | DSR | Data set ready |
| 4 | DR | Data ready |
| 5 | TDRE | Transmit data register empty |
| 6 | T_empty | Transmitter empty |
| 7 | BRK | Break detected |

## Timer Purposes on Atari ST

| Timer | Purpose |
|-------|---------|
| Timer A | Standalone / custom timing |
| Timer B | Screen graphics (hblank, sync) |
| Timer C | System timing (GSX, GEM, Desktop) - 200 Hz |
| Timer D | RS232 baud rate |
