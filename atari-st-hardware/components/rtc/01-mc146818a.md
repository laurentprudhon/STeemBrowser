# MC146818A Real-Time Clock

> The Motorola MC146818A is a real-time clock plus RAM chip that maintains system date and time.

## Overview

| Parameter | Value |
|------|----|
| Manufacturer | Motorola |
| Package | DIP24 |
| Function | Real-Time Clock Plus RAM |
| RAM size | 114 bytes (114 bytes of SRAM) |
| Oscillator | 32.768 kHz external crystal |
| Alarm | Programmable alarm interrupt |
| Registers | 11 registers (12 bytes total) |
| Address | $FFFA2D-$FFFA38 range (mapped via MFP) |

### Register A (Square Wave)

| Bit | Name | Description |
|-----|------|------|
| 0 | SQWE | Square wave enable |
| 1-3 | RS | Rate select (divider frequency) |
| 4-7 | - | Unused |

Rate select (RS):
| RS | Hz | Period |
|----|----|----|
| 0000 | 32768 | 30.5 us |
| 0001 | 4096 | 244 us |
| 0010 | 512 | 1.95 ms |
| 0011 | 256 | 3.91 ms |
| 0100 | 128 | 7.81 ms |
| 0101 | 64 | 15.625 ms |
| 0110 | 32 | 31.25 ms |
| 0111 | 16 | 62.5 ms |
| 1000 | 8 | 125 ms |
| 1001 | 4 | 250 ms |
| 1010 | 2 | 500 ms |
| 1011 | 1 | 1 s |

### Register B (Interrupt Enable)

| Bit | Name | Description |
|-----|------|------|
| 0 | UIE | Update interrupt enable |
| 1 | AIE | Alarm interrupt enable |
| 2 | PIE | Periodic interrupt enable |
| 3 | - | Unused |
| 4 | DM | Data mode (0 = BCD, 1 = binary) |
| 5 | DPE | Periodic interrupt rate enable |
| 6 | UPS | Update period select (0 = normal, 1 = update every second) |
| 7 | SET | Set mode (0 = run, 1 = stop oscillator during writes) |

### Register C (Interrupt Flags)

| Bit | Name | Description |
|-----|------|------|
| 0 | UF | Update finished flag |
| 1 | AF | Alarm flag |
| 2 | Pf | Periodic interrupt flag |
| 3 | - | Unused |
| 4-7 | - | Unused |

Note: Reading register C clears the flags.

### Date/Time Format

The MC146818A stores date/time in **BCD format** by default (binary if DM bit set):

- Seconds: 00-59
- Minutes: 00-59
- Hours: 00-23 (or 01-12 with AM/PM)
- Day of week: 1-7 (Sunday=1)
- Day of month: 01-31
- Month: 01-12
- Year: 00-99
- Century: 19 or 20

## EMulator Notes

- On the Atari ST, the MC146818A is not directly memory-mapped at a fixed address. Instead, it is accessed through the MFP's I/O port.
- The exact access mechanism on the ST varies by model (Mega STE integrates RTC differently).
- The RTC is typically used for system timing rather than real-time clock display.
- The 114 bytes of onboard RAM are used for NVRAM (Non-Volatile RAM) in Mega STE models with battery backup.
- On the original ST (520ST, 1040ST), the RTC provides only date/time via the MFP; NVRAM bytes are not utilized.
- The Mega STE has a battery-backed NVRAM section (64 bytes) in the RTC chip.
