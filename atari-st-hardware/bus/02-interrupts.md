# Interrupt System

> The Atari ST interrupt system: 68000 exception handling, MFP interrupt controller, and GPU interrupt integration.

## Interrupt Categories

### 68000 Exceptions
| Exception | Vector | Description |
|--|--|--|
| Bus error | $08 | Address not in memory |
| Address error | $0C | Unaligned address access |
| Illegal instruction | $10 | Invalid opcode |
| Zero divide | $14 | Division by zero |
| CHK | $18 | CHK instruction failed |
| TRAPV | $1C | Trap-on-overflow |
| Privilege violation | $20 | Illegal instruction in user mode |
| Trace | $24 | Single-step after current instruction |
| Line-A | $28 | Atari Line-A call (GEM/Xbios) |
| Line-F | $2C | Atari Line-F call |
| Uninitialized interrupt | $3C | Spurious interrupt |

### 68000 Levels
| Level | Auto-vector | Source |
|----|--|--|
| 1 | $000064 | BLANK (horizontal blanking) |
| 2 | $000068 | HBLANK (Glue) |
| 3 | $00006C | Reserved |
| 4 | $000070 | GPU op complete |
| 5 | $000074 | Reserved |
| 6 | $000078 | MFP (Timers/GPI) |
| 7 | $00007C | NMI |

## MFP Interrupt Configuration on Atari ST

### Priority and Sources

| Priority | IPL | Source | Register |
|--|--|--|--|
| 0 | -- | Parallel port busy (GPI0) | GPIOR bit 0 |
| 1 | -- | RS232 DCD (GPI1) | GPIOR bit 1 |
| 2 | -- | RS232 CTS (GPI2) | GPIOR bit 2 |
| 3 | 4 | GPU op done (GPI3) | GPIOR bit 3 |
| 4 | -- | RS232 baud rate (Timer D) | TCR bit |
| 5 | 6 | Timer C (system clock) | TCR bit |
| 6 | -- | Keyboard/MIDI (GPI4) | GPIOR bit 4 |
| 7 | -- | FDC (GPI5) | GPIOR bit 5 |
| 8 | 8 | Horizontal blanking (Timer B) | TBR bit |
| 9 | -- | RS232 Tx error | TCR |
| 10 | -- | RS232 Tx buffer empty | TCR |
| 11 | -- | RS232 Rx error | TCR |
| 12 | -- | RS232 Rx buffer full | TCR |
| 13 | -- | Timer A | TCR |
| 14 | -- | RS232 RI (GPI6) | GPIOR bit 6 |
| 15 | 15 | Monochrome detect (GPI7) | GPIOR bit 7 |

### Vector Table Configuration

The MFP's Vector Base Address Register (VBA) at `$FFFA17` configures the base vector for MFP interrupts:
- Default on the ST: the MFP autovectors start at a configurable address
- The MFP adds its priority to the VBA to compute the final vector address

## GPU Interrupt Integration

The GPU (Glue + MMU) generates two periodic interrupts:

### Horizontal Blanking (HBLANK)
```
At 8 MHz clock with Glue:
- Horizontal period ≈ 63.556 us (NTSC) / ~64 us (PAL)
- Generated by Glue timer counting pixel clock
- Interrupt level: IPL2 → autovector $000068
- Timer B on MFP can be configured for hblank
```

### Vertical Blanking
```
- Vertical period: 16.667 ms (NTSC, 60 Hz) / 20 ms (PAL, 50 Hz)
- Generated by counting horizontal lines
- Interrupt level: IPL6 (MFP timer C or GPI)
- Autovector: $000078 (Level 6)
```

## Interrupt Vector Table on Atari ST

The standard ST vectors are:

| Vector | Address | Default Handler |
|--------|--------|--|
| TRAP 0 | $000080 | GEMDOS: system_call_int_0 |
| TRAP 1 | $000084 | SuperBus call |
| TRAP 2 | $000088 | GEMDOS: system_call_int_2 |
| TRAP 3 | $00008C | GEMDOS: system_call_int_3 |
| TRAP 4 | $000090 | GEMDOS: system_call_int_4 |
| TRAP 5 | $000094 | GEMDOS: system_call_int_5 |
| TRAP 6 | $000098 | Not used |
| TRAP 7 | $00009C | Not used |
| MFP VBL (int 2) | $000068 | TOS VBlank handler |
| GPU (level 4) | $000070 | GPU done handler |
| MFP level 6 | $000078 | TOS system clock handler |
| NMI (level 7) | $00007C | TOS NMI handler |

## VBLANK Timer

The TOS uses the VBLANK interrupt for:
1. **System timing**: 50/60 Hz system clock (GEM timing)
2. **Screen updates**: GEM desktop redraws
3. **User callbacks**: Application VBL queues
4. **Input scanning**: Mouse/joystick polling

The VBLANK handler is typically at vector address `$000078-$00007B` (Level 6 autovector on ST) or `$000068-00006B` (Level 2 autovector, HBLANK).
