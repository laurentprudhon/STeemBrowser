# MC68901 MFP Implementation - Steem SSE

## Overview

The MC68901 MFP (Multi-Function Peripheral) is a versatile chip used in the Atari ST for various I/O functions, including timers, interrupts, serial communication, and parallel I/O. It serves as the main peripheral controller for the system.

This document describes how the MC68901 MFP is emulated in Steem SSE, including its architecture, timer implementation, interrupt handling, and I/O functionality.

## Hardware Background

### MFP Chip Functions

The MC68901 MFP performs several critical functions in the Atari ST:

1. **Interrupt Control**: Manages 16 interrupt sources with programmable priority
2. **Timer Functions**: Provides 4 programmable timers (A, B, C, D)
3. **Serial I/O**: USART for RS232 communication
4. **Parallel I/O**: 8-bit general purpose I/O port
5. **Bus Arbitration**: Handles bus requests and acknowledgments

### Key Specifications
- **Package**: PDIP64 (64-pin Plastic Dual In-line Package)
- **Clock Input**: 2.451 MHz (derived from system clock)
- **Interrupts**: 16 sources with 8 priority levels
- **Timers**: 4 independent 16-bit timers
- **USART**: Full-duplex asynchronous serial communication
- **GPIP**: 8-bit general purpose I/O port

## Core Functionality

### 1. Register Access

The MFP registers are memory-mapped and accessed through read/write functions:

```cpp
// In mfp.cpp
BYTE mfp_read_byte(MEM_ADDRESS ad) {
    // Handle MFP register reads
    if (ad >= 0xFFFA00 && ad <= 0xFFFA2F) {
        int reg = (ad & 0x1F) - 1; // Convert address to register index
        if (reg >= 0 && reg < N_MFP_REGS) {
            return Mfp.reg[reg];
        }
    }
    return 0xFF; // Invalid address
}

void mfp_write_byte(MEM_ADDRESS ad, BYTE value) {
    // Handle MFP register writes
    if (ad >= 0xFFFA00 && ad <= 0xFFFA2F) {
        int reg = (ad & 0x1F) - 1; // Convert address to register index
        if (reg >= 0 && reg < N_MFP_REGS) {
            Mfp.reg[reg] = value;
            
            // Handle special cases
            switch (reg) {
                case MFPR_TACR:
                case MFPR_TBCR:
                case MFPR_TCDCR:
                    // Timer control register changed
                    Mfp.UpdateTimerControls();
                    break;
                case MFPR_IERA:
                case MFPR_IERB:
                case MFPR_IMRA:
                case MFPR_IMRB:
                    // Interrupt control changed
                    Mfp.CalcInterruptsEnabled();
                    break;
                // ... other special cases
            }
            
            // Record last write
            Mfp.LastRegisterWritten = reg;
            Mfp.LastRegisterWrittenValue = value;
        }
    }
}
```

### 2. Timer Implementation

The MFP has 4 independent 16-bit timers (A, B, C, D) with various modes.

#### Timer Control

```cpp
void TMC68901::UpdateTimerControls() {
    // Update timer control registers based on current register values
    
    for (int i = 0; i < N_MFP_TIMERS; i++) {
        timer_control[i] = GetTimerControlRegister(i);
    }
}

BYTE TMC68901::GetTimerControlRegister(int n) {
    // Get timer control register for timer n
    ASSERT((n & 3) == n);
    
    switch (n) {
        case MFP_TIMER_A: return reg[MFPR_TACR];
        case MFP_TIMER_B: return reg[MFPR_TBCR];
        case MFP_TIMER_C:
        case MFP_TIMER_D: return reg[MFPR_TCDCR];
        default: return 0;
    }
}
```

#### Timer Operation

```cpp
void TMC68901::InitTimers() {
    // Initialize all timers
    for (int i = 0; i < N_MFP_TIMERS; i++) {
        Counter[i] = 0;
        Prescale[i] = 0;
        Wobble[i] = 0;
        timer_period_tclk[i] = 0;
        nTimeouts[i] = 0;

}

void TMC68901::CalcTimerPeriod(int t) {
    // Calculate timer period based on control register
    // This determines how fast the timer counts down
    
    BYTE control = timer_control[t];
    int prescale = (control >> 5) & 3; // Prescale bits
    bool use_xtal = (control & BIT_3) != 0; // Use external clock
    
    // Calculate period in MFP clock cycles
    if (use_xtal) {
        // External clock mode
        timer_period_tclk[t] = 1; // Count every external clock
    } else {
        // Internal clock mode with prescaler
        timer_period_tclk[t] = 1 << prescale; // 1, 2, 4, or 8
    }
}
```

#### Timer Ticking

```cpp
void TMC68901::TimerATick() {
    // Timer A tick (special handling for Timer A)
    // Timer A can be used in various modes including event counting
    
    if (timer_control[MFP_TIMER_A] & BIT_0) {
        // Event counting mode
        // Count on external events
    } else {
        // Normal counting mode
        Counter[MFP_TIMER_A]--;
        if (Counter[MFP_TIMER_A] == 0) {
            // Timer expired
            Counter[MFP_TIMER_A] = reg[MFPR_TADR]; // Reload from data register
            
            // Trigger interrupt if enabled
            if (mfp_interrupt_enabled[MFP_INT_TIMER_A]) {
                SetPending(MFP_INT_TIMER_A, A_S_T);
            }
        }
    }
}
```

```cpp
void TMC68901::GetInterrupt(BYTE irq, COUNTER_VAR when_set) {
    // Signal an interrupt from a peripheral
    // irq: interrupt source
    // when_set: time when interrupt should be triggered
    
    // Check if this interrupt is enabled
    if (irq < N_MFP_IRQS && mfp_interrupt_enabled[irq]) {
        SetPending(irq, when_set);
    }
}

void TMC68901::SetPending(BYTE irq, COUNTER_VAR when_set) {
    // Set an interrupt as pending
    
    // Record interrupt information
    IrqInfo[irq].IsGpip = (irq >= MFP_INT_CENTRONICS_BUSY && irq <= MFP_INT_MONOCHROME_MONITOR_DETECT);
    IrqInfo[irq].IsTimer = (irq >= MFP_INT_TIMER_A && irq <= MFP_INT_TIMER_D);
    if (IrqInfo[irq].IsTimer) {
        IrqInfo[irq].Timer = irq - MFP_INT_TIMER_A;
    }
    
    // Set pending flag
    if (irq < 8) {
        reg[MFPR_IPRA] |= (1 << irq);
    } else {
        reg[MFPR_IPRB] |= (1 << (irq - 8));
    }
    
    // Check if this is the highest priority pending interrupt
    if (irq > NextIrq) {
        NextIrq = irq;
    }
}
```

#### Interrupt Acknowledge

```cpp
void TMC68901::Iack(char irq) {
    // Interrupt acknowledge process
    // This is called when the CPU acknowledges an interrupt
    
    // Clear in-service flag for this interrupt
    if (irq < 8) {
        reg[MFPR_ISRA] &= ~(1 << irq);
    } else {
        reg[MFPR_ISRB] &= ~(1 << (irq - 8));
    }
    
    // Clear pending flag
    if (irq < 8) {
        reg[MFPR_IPRA] &= ~(1 << irq);
    } else {
        reg[MFPR_IPRB] &= ~(1 << (irq - 8));
    }
    
    // Update next interrupt
    UpdateNextIrq(A_S_T);
}
```

### 4. GPIP (General Purpose I/O Port)

The MFP has an 8-bit general purpose I/O port (GPIP) that can be used for various purposes.

#### GPIP Implementation

```cpp
void mfp_gpip_set_bit(int bit, bool set) {
    // Set or clear a bit in the GPIP register
    // This is called by peripheral devices to signal interrupts
    
    if (set) {
        Mfp.reg[MFPR_GPIP] |= (1 << bit);
    } else {
        Mfp.reg[MFPR_GPIP] &= ~(1 << bit);
    }
    
    // Check if this bit change should trigger an interrupt
    BYTE ddr = Mfp.reg[MFPR_DDR]; // Data Direction Register
    BYTE aer = Mfp.reg[MFPR_AER]; // Active Edge Register
    
    if ((ddr & (1 << bit)) == 0) {
        // Bit is configured as input
        // Check if this transition matches the active edge
        bool active_edge = (aer & (1 << bit)) != 0;
        bool current_state = (Mfp.reg[MFPR_GPIP] & (1 << bit)) != 0;
        
        // If we're transitioning to the active edge state
        if (current_state == active_edge) {
            // Trigger GPIP interrupt for this bit
            Mfp.GetInterrupt(mfp_gpip_irq[bit], A_S_T);
        }
    }
}
```

#### USART Implementation

```cpp
// In rs232.cpp (USART is used for RS232)
void rs232_write_byte(MEM_ADDRESS ad, BYTE value) {
    if (ad == 0xFFFA29) {
        // UCR (USART Control Register)
        Mfp.reg[MFPR_UCR] = value;
        UpdateRs232State();
    } else if (ad == 0xFFFA2F) {
        // UDR (USART Data Register)
        Mfp.reg[MFPR_UDR] = value;
        
        // If transmitter is enabled, start transmission
        if (Mfp.reg[MFPR_UCR] & BIT_3) { // Transmitter enable
            StartRs232Transmission();
        }
    }
}

BYTE rs232_read_byte(MEM_ADDRESS ad) {
    if (ad == 0xFFFA2B) {
        // RSR (Receiver Status Register)
        return Mfp.reg[MFPR_RSR];
    } else if (ad == 0xFFFA2D) {
        // TSR (Transmitter Status Register)
        return Mfp.reg[MFPR_TSR];
    } else if (ad == 0xFFFA2F) {
        // UDR (USART Data Register)
        return Mfp.reg[MFPR_UDR];
    }
    return 0xFF;
}
```

```cpp
    // This avoids recalculating on every timer tick

    int prescale = (control >> 5) & 3;
```

## Conclusion

The MC68901 MFP emulation in Steem SSE is a **highly accurate implementation** that faithfully reproduces the behavior of the real Motorola MC68901 Multi-Function Peripheral chip. The implementation:

- **Provides accurate register access** for all 24 registers
- **Implements 4 independent timers** with various modes
- **Handles a sophisticated interrupt system** with 16 sources and programmable priority
- **Manages GPIP** for peripheral interrupts
- **Includes USART** for serial communication
- **Integrates with all peripherals** (FDC, IKBD, MIDI, etc.)
- **Generates accurate interrupts** for the CPU

The MFP emulation serves as the **peripheral control center** for the entire Atari ST system, providing the interface between the CPU and all the various I/O devices. It is one of the most complex and important components in the Steem SSE emulator.

While the MFP emulation is highly accurate, some timing details and edge cases may not be perfectly reproduced. However, for the vast majority of software, the MFP emulation provides sufficient accuracy for correct operation.
