# YM2149 PSG Implementation - Steem SSE

## Overview

The YM2149 (also known as AY-3-8910 or its variants) is a Programmable Sound Generator (PSG) chip used in the Atari ST for sound generation. It provides 3 tone channels, 1 noise channel, and an envelope generator, making it capable of producing a wide variety of sounds and music.

This document describes how the YM2149 PSG is emulated in Steem SSE, including its architecture, sound generation, register access, and integration with the sound system.

## Hardware Background

### PSG Chip Functions

The YM2149 PSG performs the following functions in the Atari ST:

1. **Tone Generation**: 3 independent tone channels with programmable frequency
2. **Noise Generation**: 1 noise channel with programmable period
3. **Envelope Generation**: Programmable envelope for amplitude modulation
4. **Mixer**: Controls which channels are enabled and their volume
5. **I/O Ports**: 2 general-purpose I/O ports (A and B)

### Key Specifications
- **Package**: PDIP40 (40-pin Plastic Dual In-line Package)
- **Clock Input**: 2 MHz (derived from system clock)
- **Channels**: 3 tone + 1 noise (can be mixed)
- **Frequency Range**: 0.1 Hz to 125 kHz (theoretical)
- **Volume Control**: 16 levels per channel (0-15)
- **Envelope**: 16-step programmable envelope

### 1. Register Access

The PSG registers are accessed through memory-mapped I/O:

```cpp
// In psg.cpp
void psg_set_reg(BYTE old_val, BYTE new_val) {
    // Set PSG register
    // old_val: previous value (for comparison)
    // new_val: new value to set
    
    // Store the new value
    psg_reg[psg_reg_select] = new_val;
    
    // Handle special cases based on register
    switch (psg_reg_select) {
        case PSGR_TONE_PERIOD_A_LOW:
        case PSGR_TONE_PERIOD_A_HIGH:
        case PSGR_TONE_PERIOD_B_LOW:
        case PSGR_TONE_PERIOD_B_HIGH:
        case PSGR_TONE_PERIOD_C_LOW:
        case PSGR_TONE_PERIOD_C_HIGH:
            // Tone period changed - update channel
            UpdateChannel(psg_reg_select / 2);
            break;
            
        case PSGR_NOISE_PERIOD:
            // Noise period changed
            UpdateNoise();
            break;
            
        case PSGR_MIXER:
            // Mixer changed - update channel enables
            UpdateMixer();
            break;
            
        case PSGR_AMPLITUDE_A:
        case PSGR_AMPLITUDE_B:
        case PSGR_AMPLITUDE_C:
            // Amplitude changed
            UpdateAmplitude(psg_reg_select - PSGR_AMPLITUDE_A);
            break;
            
        case PSGR_ENVELOPE_PERIOD_LOW:
        case PSGR_ENVELOPE_PERIOD_HIGH:
            // Envelope period changed
            UpdateEnvelopePeriod();
            break;
            
        case PSGR_ENVELOPE_SHAPE:
            // Envelope shape changed
            UpdateEnvelopeShape();
            break;
    }
}
```

### 2. Sound Generation

The PSG generates sound through a combination of tone, noise, and envelope generators.

#### Tone Generation

```cpp
// In psg.cpp (low-level emulation)
#if defined(SSE_YM2149_LL)
void TYM2149::psg_write_buffer(DWORD to_t, bool vbl) {
    // Low-level PSG emulation
    // This provides more accurate sound generation
    
    // Calculate cycles since last sample
    COUNTER_VAR cycles = to_t - time_of_last_sample;
    time_of_last_sample = to_t;
    
    // Update all channels
    for (int i = 0; i < NUM_CHANNELS; i++) {
        if (tone_enabled[i]) {
            // Update tone counter
            m_count[i] -= cycles;
            if (m_count[i] <= 0) {
                // Tone period elapsed - toggle output
                m_output[i] ^= 1;
                m_count[i] += tone_period[i];
            }
        }
    }
    
    // Update noise generator
    if (noise_enabled[0] || noise_enabled[1] || noise_enabled[2]) {
        m_count_noise -= cycles;
        if (m_count_noise <= 0) {
            // Noise period elapsed - update noise
            UpdateNoiseGenerator();
            m_count_noise += m_prescale_noise;
        }
    }
    
    // Update envelope generator
    if (m_env_step != 0) {
        m_count_env -= cycles;
        if (m_count_env <= 0) {
            // Envelope period elapsed - update envelope
            UpdateEnvelope();
            m_count_env += env_period;
        }
    }
    
    // Generate output sample
    GenerateSample();
}

void TYM2149::UpdateNoiseGenerator() {
    // Update noise generator
    // The YM2149 uses a 17-bit LFSR (Linear Feedback Shift Register)
    
    if (m_rng & 1) {
        m_rng ^= 0x24000; // Feedback for 17-bit LFSR
    }
    m_rng >>= 1;
}

void TYM2149::UpdateEnvelope() {
    // Update envelope generator
    // The envelope has 4 phases: attack, alternate, sustain, release
    
    if (m_holding) {
        // In hold phase - do nothing
        return;
    }
    
    if (m_alternate) {
        // Alternate phase
        if (m_attack) {
            // Attack phase
            m_env_step--;
            if (m_env_step == 0) {
                m_attack = false;
                m_env_step = m_env_step_mask;
            }
        } else {
            // Decay phase
            m_env_step++;
            if (m_env_step == m_env_step_mask) {
                m_attack = true;
                m_env_step = 0;
            }
        }
    } else {
        // Non-alternate (sustain) phase
        if (m_attack) {
            // Attack phase
            m_env_step--;
            if (m_env_step == 0) {
                m_attack = false;
                m_holding = true;
            }
        } else {
            // Release phase
            m_env_step++;
            if (m_env_step == m_env_step_mask) {
                m_holding = true;
            }
        }
    }
    
    // Update envelope volume
    m_env_volume = psg_envelope_level[m_env_step & 7][m_env_step >> 3];
}

void TYM2149::GenerateSample() {
    // Generate output sample by mixing all channels
    
    int sample = 0;
    
    for (int i = 0; i < NUM_CHANNELS; i++) {
        if (tone_enabled[i] || noise_enabled[i]) {
            // Get channel output
            BYTE output = m_output[i];
            if (noise_enabled[i]) {
                output &= (m_rng & 1); // Mix with noise
            }
            
            // Apply amplitude
            int volume = m_vol_enabled[i] ? m_env_volume : psg_flat_volume_level[psg_reg[PSGR_AMPLITUDE_A + i]];
            
            // Add to sample
            sample += output * volume;
        }
    }
    
    // Output sample to sound system
    // ... sound mixing
}
#endif
```

### 3. Channel Management

The PSG has 3 tone channels (A, B, C) and 1 noise channel that can be mixed with any tone channel.

#### Channel Configuration

```cpp
// In psg.cpp
void TYM2149::UpdateChannel(int channel) {
    // Update channel configuration
    // channel: 0-2 (A, B, C)
    
    // Get tone period
    WORD period = (psg_reg[channel * 2 + 1] << 8) | psg_reg[channel * 2];
    tone_period[channel] = period;
    
    // Check if tone is enabled
    tone_enabled[channel] = (psg_reg[PSGR_MIXER] & (1 << channel)) != 0;
    
    // Check if noise is enabled for this channel
    noise_enabled[channel] = (psg_reg[PSGR_MIXER] & (0x8 << channel)) != 0;
    
    // Check if envelope is enabled for this channel
    m_vol_enabled[channel] = (psg_reg[PSGR_MIXER] & (0x10 << channel)) != 0;
}

void TYM2149::UpdateMixer() {
    // Update mixer configuration
    for (int i = 0; i < NUM_CHANNELS; i++) {
        UpdateChannel(i);
    }
    
    // Update noise configuration
    UpdateNoise();
    
    // Update envelope configuration
    UpdateEnvelopePeriod();
    UpdateEnvelopeShape();
}
```

### 4. Envelope Generator

The PSG has a programmable envelope generator that can modulate the amplitude of the channels.

#### Envelope Configuration

```cpp
void TYM2149::UpdateEnvelopePeriod() {
    // Update envelope period
    env_period = (psg_reg[PSGR_ENVELOPE_PERIOD_HIGH] << 8) | psg_reg[PSGR_ENVELOPE_PERIOD_LOW];
    
    // If period is 0, envelope is disabled
    if (env_period == 0) {
        m_env_step = 0;
    }
}

void TYM2149::UpdateEnvelopeShape() {
    // Update envelope shape
    BYTE shape = psg_reg[PSGR_ENVELOPE_SHAPE];
    
    // Extract shape parameters
    m_holding = (shape & BIT_0) != 0;
    m_alternate = (shape & BIT_1) != 0;
    m_attack = (shape & BIT_2) != 0;
    m_env_step_mask = shape >> 4; // Upper 4 bits
    
    // Reset envelope state
    m_env_step = 0;
    m_env_volume = 0;
}
```

## Performance Optimizations

### 1. Fixed Volume Table

The PSG uses a precomputed volume table for faster sound generation:

```cpp
// In psg.cpp
bool TYM2149::LoadFixedVolTable(bool check_dmamix) {
    // Load or generate fixed volume table
    // This provides faster volume calculations
    
    if (p_fixed_vol_3voices == nullptr) {
        p_fixed_vol_3voices = new WORD[16*16*16]; // 4096 entries
        
        // Generate volume table
        for (int a = 0; a < 16; a++) {
            for (int b = 0; b < 16; b++) {
                for (int c = 0; c < 16; c++) {
                    p_fixed_vol_3voices[a*256 + b*16 + c] = 
                        CalculateMixedVolume(a, b, c);
                }
            }
        }
    }
    
    return true;
}

void TYM2149::FreeFixedVolTable() {
    if (p_fixed_vol_3voices != nullptr) {
        delete[] p_fixed_vol_3voices;
        p_fixed_vol_3voices = nullptr;
    }
}
```

### 2. Sample Buffering

The PSG uses sample buffering for efficient sound output:

```cpp
// In psg.cpp
void TYM2149::psg_write_buffer(DWORD to_t, bool vbl) {
    // Generate samples in batches
    // This reduces the overhead of frequent sound updates
    
    // Calculate how many samples to generate
```

## Conclusion

The YM2149 PSG emulation in Steem SSE is a **highly accurate implementation** that faithfully reproduces the behavior of the real Yamaha YM2149 Programmable Sound Generator chip. The implementation:

- **Provides accurate register access** for all 16 registers
- **Generates 3 tone channels** with programmable frequency
- **Implements noise generation** with a 17-bit LFSR
- **Handles envelope generation** with programmable shapes
- **Manages volume control** with 16 levels per channel
- **Mixes channels** for final audio output
- **Integrates with the sound system** for audio output

The PSG emulation provides the **sound generation backbone** for the Atari ST, allowing it to reproduce the characteristic sound of the platform with high accuracy. While the digital emulation may not perfectly match the analog sound of the real hardware, it provides sufficient accuracy for the vast majority of software.

Steem SSE offers both a standard PSG emulation and an optional low-level emulation (SSE_YM2149_LL) that provides even higher accuracy at the cost of increased resource usage.
